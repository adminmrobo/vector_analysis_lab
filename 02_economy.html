경기순환시계 — 경기의 크기와 국면을 각도로

원자료: 카드 2/4 (원통 자) ρ·φ·z방법: 반지름 = 크기, 각도 = 국면, 높이 = 시간일상: 경제 뉴스의 "경기 국면"
모아뉴스에서 "경기가 둔화 국면"이래요. 국면이 시계처럼 돈다는데, 1부 시계판이랑 같은 거예요?

왜 이 방법을 쓰나

문제: 경기는 좋아졌다 나빠졌다를 반복합니다. 숫자 하나(성장률)만 보면 "지금 오르는 중인지, 꼭대기를 지났는지"가 안 보입니다.

앞 방의 한계: 1부 방 2에서는 달처럼 정해진 순서로 도는 데이터를 시계판에 놓았습니다. 경기는 크기도, 도는 속도도 매번 다릅니다.

해법: 가로에 "추세보다 위·아래(수준)", 세로에 "좋아지는 중·나빠지는 중(변화)"을 놓습니다. 그러면 점이 시계 방향으로 돕니다. 반지름은 경기의 크기, 각도는 국면입니다. 이 페이지의 축 배치와 국면 이름(확장·수축)은 설명용이며, 공식 경기순환시계는 상승·하강 같은 이름과 다른 배치를 쓸 수 있습니다.

쉽게 말하면 1부 피자처럼, 큰 원(큰 경기)일수록 같은 국면 변화에도 실제로 크게 움직입니다.

시아수준이 +1, 변화가 −1이면 어느 국면이에요?

말로 먼저: 추세보다 위에 있지만 내려오는 중입니다. 그러면 오른쪽 아래, "둔화" 국면입니다. 원점에서 거리는 피타고라스로, 각도는 오른쪽에서 몇 도 내려왔는지로 읽습니다.

학교 수학으로 보면: 좌표평면의 사분면, 피타고라스 정리, 삼각함수(각도)

숫자로 한 번 해 보기

  4. 같은 30° 국면 이동: 반지름 1.41이면 1.41 × 0.524 = 0.74, 반지름 0.5면 0.26 움직임

왜 이 방법을 쓰나

문제: 세 환율이 서로 안 맞으면, 한 바퀴 돌기만 해도 돈이 생깁니다(차익거래). 그런 틈이 오래 남을 수 있을까요?

앞 방의 한계: 1부 방 6에서는 "한 바퀴에 남는 돈 = 회전"이라는 것까지만 봤습니다.

해법: 비율을 곱하는 대신 로그로 바꾸면 더하기가 됩니다. 한 바퀴 로그 합이 0이면 회전 0. 여러 사람이 틈을 이용하면 비싼 쪽은 내리고 싼 쪽은 올라 회전이 0으로 다가갑니다. 수수료가 있으면 그보다 작은 틈은 남습니다.

쉽게 말하면 줄이 서로 다른 세 계산대가 있으면, 사람들이 짧은 줄로 몰려 줄 길이가 곧 비슷해집니다.

시아·모아가 묻고, 하루가 풀어 봅니다

모아1부 숫자(1,400원 · 150엔 · 950원)로 한 바퀴 비율은 얼마예요?

말로 먼저: 처음 돈에 세 환율을 차례로 곱하면 한 바퀴 뒤 돈이 나옵니다. 처음보다 몇 배인지가 "한 바퀴 비율"입니다. 이 비율이 1이면 회전 0, 1보다 크면 돈이 남습니다.

학교 수학으로 보면: 지수와 로그(곱셈을 덧셈으로), 비율

숫자로 한 번 해 보기
  1. 한 바퀴 비율 = 1,425 ÷ 1,400 = 1.0179 (1.79% 남음)
  2. 로그로 쓰면 0.0177 → 0이 아님 = 회전 있음
  3. 사람들이 몰려 100엔 값이 950 → 945 → 941.5원으로 내려가면 남는 돈 25 → 17.5 → 12.25원
  4. 거래마다 수수료 1%면 0.99³ × 1.0179 = 0.988 → 오히려 손해
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
∮ ln(환율)한 바퀴 로그 합0이면 회전 0(높이 지도 하나로 설명됨)
(1 − f)³—수수료 f를 세 번 냄
f* ≈ 0.59%—이 수수료면 25원 틈이 딱 사라짐
하루틈은 사람들이 메우고, 수수료보다 작은 틈만 남아요. 그래서 공짜 돈은 오래 안 가요!
일상으로 치면여러 환전소 환율이 비슷한 까닭도, 차이를 노리는 사람들이 금방 틈을 메우기 때문입니다.
다음 부에서는3부 방 15에서 "돌려도 남는 것만 남긴다"는 생각이 위치를 각도로 넣는 방법(RoPE)으로 이어집니다.
초파리 연구원"한 라운드 진행"을 몇 번 눌러 봐. 남는 돈이 어떻게 줄어들어?
주판봇수수료를 넣으면 남는 돈이 바로 바뀌어요. 계산은 제가!
실험 ⑨ 틈이 메워지는 시장 (가상 환율)라운드를 진행하거나 수수료를 바꿔 보세요
풀이 회전이 0이 아닌 시장에서는 "돌기만 해도" 이익이 생깁니다. 그 이익을 노리는 거래가 가격을 움직여 회전을 0 쪽으로 밀어냅니다. 수수료는 "이만큼 작은 회전은 그냥 두는" 문턱 역할을 합니다.

자금순환의 샘과 배수구 — 누가 돈을 내보내고 누가 빨아들이나

원자료: 네 카드의 DIVERGENCE 줄방법: 부문별 순자금(내보낸 − 받은), 전체 합일상: "가계는 저축, 기업은 투자"
모아자금순환표에 가계·기업·정부·해외가 나와요. 이것도 지하철역처럼 볼 수 있어요?
하루이건 1부 방 5랑 똑같아요! 각 부문이 역이고, 사람 대신 돈이 드나들어요.

왜 이 방법을 쓰나

문제: 경제 전체에서 어느 부문이 돈을 남겨 내보내고(빌려주고), 어느 부문이 돈을 끌어다 쓰는지(빌리는지) 알고 싶습니다.

앞 방의 한계: 1부 방 5에서는 역 하나의 발산만 봤고, 도시 전체 합 이야기는 대시보드에서 살짝 봤습니다.

해법: 부문마다 "남겨서 내보낸 돈 − 끌어다 쓴 돈"(순자금)을 셉니다. +는 샘, −는 배수구. 해외까지 넣은 경제 전체를 큰 상자로 보면 합은 0입니다. 누군가 빌려준 돈은 누군가 빌린 돈이기 때문입니다.

쉽게 말하면 친구 넷이 돈을 주고받으면, 각자 남은 차액을 다 더하면 0입니다.

시아·모아가 묻고, 하루가 풀어 봅니다

시아가계 +100조, 기업 −80조, 정부 −30조면 해외는요?

말로 먼저: 네 부문 합이 0이어야 하니, 앞의 셋을 더한 값의 반대가 해외입니다. 100 − 80 − 30 = −10이므로 해외는 +10조입니다.

학교 수학으로 보면: 수의 덧셈·뺄셈, 부호

숫자로 한 번 해 보기
  1. 가계 +100조 (샘: 저축으로 돈을 내보냄)
  2. 기업 −80조, 정부 −30조 (배수구: 끌어다 씀)
  3. 셋의 합 −10조 → 해외 +10조
  4. 네 부문 합계 = 0 (교육용 가상 숫자)

원자료: 네 카드의 SCALAR LAPLACIAN 줄방법: 새 값 = 내 값 + 속도 × (이웃 평균 − 내 값)일상: "옆 동네가 오르면 우리 동네도"

왜 이 방법을 쓰나

문제: 한 곳의 값이 주변으로 번져 가는 모습(파급)을 숫자로 따라가고 싶습니다.

앞 방의 한계: 1부 방 7에서는 주변 평균과의 차이로 튀는 곳(윤곽선)을 찾기만 했습니다.

해법: 매 단계 "이웃 평균 − 내 값"의 일부만큼 내 값을 고칩니다. 높은 곳은 내려오고 낮은 곳은 올라와, 지도가 점점 고르게 됩니다. 열이 퍼지는 계산과 같은 모양입니다.

쉽게 말하면 뜨거운 국에 찬물을 부으면 온도가 고르게 섞여 가는 것과 같습니다.

시아·모아가 묻고, 하루가 풀어 봅니다

모아우리 동네 6억, 이웃 넷이 5억이면 한 단계 뒤엔요?

말로 먼저: 이웃 평균과의 차이를 먼저 구하고, 그 차이의 반만큼(속도 0.5) 다가갑니다. 이웃도 우리 동네 쪽으로 조금 올라옵니다.

학교 수학으로 보면: 평균, 일차식, 수열(단계마다 반복)

숫자로 한 번 해 보기

  2. 속도 0.5 → 6 + 0.5 × (−1) = 5.5억

  4. 단계를 거듭하면 모두 비슷한 값으로
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
u ← u + α ∇²u유에 알파 라플라시안 유를 더함한 단계 섞기(α = 속도)
∇²u ≈ 이웃 평균 − u—1부 방 7과 같은 계산
하루찾을 때 쓴 차이를 이번엔 고르게 만드는 데 썼어요. 같은 라플라시안!

왜 이 방법을 쓰나

문제: 자산 여러 개를 섞을 때 "얼마나 같이 움직이나(상관)"가 위험을 정합니다. 그런데 상관 숫자를 마음대로 정하면 말이 안 되는 조합이 생깁니다.

앞 방의 한계: 방 8~11은 크기와 흐름을 봤습니다. 이번에는 두 움직임이 이루는 "방향"입니다.

해법: 자산의 움직임을 화살표로 보면, 상관은 두 화살표 사이 각도의 코사인입니다. 각도로 정하면 상관은 늘 −1~1 안이고, 세 자산이면 화살표 끝이 지구본(구) 위의 점이 되어 말이 안 되는 조합이 생기지 않습니다.

쉽게 말하면 두 사람이 같은 방향을 보면 상관 1, 직각이면 0, 반대면 −1입니다.

시아·모아가 묻고, 하루가 풀어 봅니다

시아각도가 60°면 상관은 얼마예요? 반반 섞으면 위험은요?

말로 먼저: 코사인 60°는 0.5입니다. 두 자산의 흔들림(표준편차)이 둘 다 1이라면, 반반 섞은 흔들림의 제곱(분산)은 (1 + 상관) ÷ 2입니다.

학교 수학으로 보면: 삼각함수 cos, 벡터의 내적

숫자로 한 번 해 보기
  1. θ = 60° → c = cos 60° = 0.5
  2. 반반 섞은 분산 = (1 + 0.5) ÷ 2 = 0.75, 흔들림 √0.75 = 0.87
  3. θ = 90°(상관 0) → 분산 0.5, 흔들림 0.71
  4. 상관 0.9 · 0.9 · −0.9 세 개를 한꺼번에 고르면 말이 안 되는 조합 (확인 값 −2.89 < 0)
식으로 보면 (몰라도 됩니다)
식 조각읽는 법뜻
c = cos θ시는 코사인 세타상관 = 두 화살표 사이 각도의 코사인
1 + 2abc − a² − b² − c²—세 상관 a, b, c가 말이 되는지 확인 값(0 이상이어야 함)
